MODULE 3: THE CARD STACK RENDER ENGINE

Visual Layout: The main screen is beautifully empty (backgroundColor: #EBE5D9), filled only by the Background Base. In the direct center sits a stack of 3 cards.

3.1. Rendering Logic:
Extract the top 3 videos from the Zustand store's videos array. Map them in reverse order so the 3rd card renders first (at the back) and the 1st card renders last (on top).

3.2. Depth Scaling (via useAnimatedStyle):
Based on the card's position (index 0, 1, or 2) in the active 3-card stack, apply static transforms to create depth:

    index === 2 (Top Card): scale: 1, translateY: 0. Applies shadows.cardTop.

    index === 1 (Middle Card): scale: 0.95, translateY: -20 (moves it slightly up to peek from behind). Applies shadows.stackMiddle.

    index === 0 (Bottom Card): scale: 0.90, translateY: -40. Applies shadows.stackBottom.

3.3. Card UI Component (The "Polaroid" Look):

    Dimensions: width: windowWidth * 0.85, height: windowHeight * 0.65.

    Shape: borderRadius: 24px, smooth curves. backgroundColor: #F7F5F0.

    Padding: 12px padding inside the card. This creates a physical white frame around the video thumbnail.

    Thumbnail Image: Takes 80% of the card's height. borderRadius: 16px. resizeMode: cover.

    Info Area: Bottom 20% of the card height. Flex-row layout. Contains Video Title (bold, max 2 lines) and Channel Name.

MODULE 4: KINETIC PHYSICS & REANIMATED GESTURES

Physics Feeling: The swipe must feel heavy, responsive, and physical.

4.1. PanGestureHandler Rules:

    Apply PanGestureHandler ONLY to the component where isTopCard === true.

    Track movement using useSharedValue(0) for translateX and translateY.

4.2. 3D Tilt Effect:
As the user drags the card left/right, it must rotate on the Z-axis, creating a tossing motion.
const rotate = useDerivedValue(() => interpolate(translateX.value, [-windowWidth/2, 0, windowWidth/2],[-10, 0, 10], Extrapolate.CLAMP) + 'deg');

4.3. Dynamic Shadow Expansion:
On gesture onBegin, animate the shadow properties from cardTop to cardFloating to simulate lifting the card off the stack. On gesture onFinalize (if returning to center), animate back to cardTop.

4.4. Gesture Thresholds & Actions (onEnd):

    RIGHT SWIPE (translateX.value > 120):

        Trigger Haptic Feedback (Heavy).

        Animate translateX off-screen withSpring.

        Overlay: A soft Olive Green (#8C9970) view fades in over the card image with opacity tied to translateX.

        Action: Open official YouTube App natively: Linking.openURL('vnd.youtube://watch?v=' + videoId).

        State: Mark video as 'archived' in SQLite, instantly remove from Zustand array.

    LEFT SWIPE (translateX.value < -120):

        Trigger Haptic Feedback (Medium).

        Animate translateX off-screen withSpring.

        Overlay: A soft Terracotta Red (#B27065) view fades in.

        Action: Delete permanently from SQLite and Zustand array.

    UP SWIPE (translateY.value < -100):

        Trigger Haptic Feedback (Light).

        withSpring reset card to center (x: 0, y: 0).

        Action: Emit event to open InfoBottomSheet.

    DOWN SWIPE (translateY.value > 100):

        Trigger Haptic Feedback (Light).

        withSpring reset card to center.

        Action: Emit event to open CommentsTopSheet.

MODULE 6: SQLITE DATABASE ARCHITECTURE (expo-sqlite)

App is Local-First. Use expo-sqlite with asynchronous queries.

6.1. Schema Initialization (Run on first launch):
code SQL

CREATE TABLE IF NOT EXISTS folders (
    id TEXT PRIMARY KEY,
    name TEXT NOT NULL,
    is_system INTEGER DEFAULT 0, -- 1 for Archive/Watch Later
    created_at INTEGER NOT NULL
);

CREATE TABLE IF NOT EXISTS videos (
    id TEXT PRIMARY KEY, -- YouTube Video ID
    title TEXT NOT NULL,
    thumbnail_url TEXT NOT NULL,
    channel_name TEXT,
    description TEXT,
    folder_id TEXT NOT NULL,
    status TEXT DEFAULT 'unread', -- 'unread' | 'archived'
    added_at INTEGER NOT NULL,
    FOREIGN KEY (folder_id) REFERENCES folders (id) ON DELETE CASCADE
);

6.2. Default Data Seed:
On first launch, auto-insert two folders:
id: 'sys_archive', name: 'Archive', is_system: 1
id: 'sys_watchlater', name: 'Watch Later', is_system: 1
MODULE 7: ZUSTAND STATE MANAGEMENT

Zustand acts as the UI bridge.
State Interface:

    videos: Video[]

    folders: Folder[]

    activeFolderId: string

Crucial UI Rule: When a card is swiped right/left, the Zustand store MUST update instantly (set((state) => ({ videos: filteredVideos }))). Do NOT wait for the SQLite query to finish before updating the UI state. Execute SQLite deletes/updates asynchronously in the background. This ensures the stack animation is instant and flawless. When the top card is removed from the array, React will naturally re-render, and the Middle Card (index 1) will become the new Top Card (index 2), smoothly expanding to scale: 1 via useAnimatedStyle.

8.2. URL Parsing & Interception (App.tsx):

Execute this precise Regex to extract the 11-character YouTube Video ID from any format (youtu.be, /watch, /shorts):
const videoIdMatch = sharedUrl.match(/^.*(youtu.be\/|v\/|u\/\w\/|embed\/|watch\?v=|&v=|shorts\/)([^#\&\?]*).*/);
