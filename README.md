# Swipetuber

Мобильное Android-приложение для организации YouTube-видео. Сохраняйте видео из YouTube в персональные папки через системный "Поделиться".

## Стек технологий

- React Native 0.81.5
- Expo SDK 54
- TypeScript
- SQLite (expo-sqlite)
- Zustand — управление состоянием
- React Navigation 7 — навигация
- Expo Share Intent — обработка входящих ссылок
- Lucide React Native — иконки

## Описание функционала

Приложение позволяет:

- Делиться ссылками на YouTube-видео из приложения YouTube прямо в Swipetuber
- Сохранять видео в персональные папки (создавать, редактировать, удалять)
- Системные папки: "Watch Later" и "Archive"
- Просматривать миниатюры, названия и описания видео
- Отмечать видео как просмотренные
- Работать оффлайн — все данные хранятся локально в SQLite

## Инструкция по запуску

### Предварительные требования

- Node.js 18+
- npm или yarn
- Android Studio (для эмулятора) или физическое устройство Android

### Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone <репозиторий>
cd "For android swipetube"
```

2. Установите зависимости:
```bash
npm install
```

3. Запустите приложение:
```bash
npx expo start
```

4. Для запуска на Android-эмуляторе нажмите `a` в терминале или сканируйте QR-код через приложение Expo Go на физическом устройстве.

### Сборка APK

```bash
npx eas build --platform android --profile preview
```
